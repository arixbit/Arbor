# Arbor Final Vector Kit v2

This package uses the exact selected Arbor artwork as the tracing source:
- same tree silhouette
- same three leaves
- same two hollow Git nodes
- same branch angles
- same Arbor wordmark from the selected image

The artwork is traced at 4× resolution from the selected master and exported as true SVG paths.
No substitute font or hand-redrawn logo geometry is used.

Included:
- SVG vector masters
- PDF vector exports
- Light/Dark PNG sizes: 16, 32, 64, 128, 256, 512, 1024
- Transparent black/white marks
- macOS iconset
- ICNS
- Xcode AppIcon sets
- actual export preview
