Interactive Rebase 取消语义补充：structured single-root、multi-root 与 native todo 在用户修改 todo 后点击 Cancel 都会先显示 Keep Editing / Discard Changes；未修改的 editor 直接关闭，避免静默丢弃编辑。

Interactive Rebase 详情分栏补充：structured single-root editor 的 todo 多选会驱动只读提交详情面板；面板直接按 revision 加载 CommitInfo，并复用 CommitDetailView 展示 metadata、changes 和 diff，同时隐藏 Log mutation actions。multi-root 详情聚合、native control-row 的完整 structured presentation、通知分组和 UI automation 仍待补齐。

Interactive Rebase 拖拽补充：标准 structured single-root todo 表支持把单行或已选中的多行拖到目标提交前，按 commit identity 保持组内顺序并恢复 selection；preserve-merges 允许 non-merge 行只在同一 native branch segment 内重排，merge anchor 与控制边界固定，跨边界移动 fail-closed；重排后 squash/fixup 暂时收窄到未重排路径。完整 Swing 行间 drop target、native control-row 结构化编辑、通知分组和 UI automation 仍为 partial。

Interactive Rebase native todo 补充：raw editor 现在带实时结构化预览，commit action 与 `label/reset/merge/exec/break/update-ref` 控制行分别呈现，未知或不完整语法仅显示警告而不替 Git 做最终判断；raw 文本仍可直接编辑并由 Git 执行。完整 control-row structured editing、跨 root 通知分组和 UI automation 仍待补齐。

Interactive Rebase multi-root 补充：每个 root 的 todo 行现在都可驱动右侧只读 commit details/changes/diff splitter；Repository 以 root-qualified identity 独立缓存，选中多个 commit 时按该 root 的 todo 顺序加载，避免不同 root 的相同 revision 字符串串库。仓库打开或详情加载失败会在当前 root 的详情区域明确显示。

Interactive Rebase command reference 补充：single-root 与 multi-root structured editor 均提供 `Commands…` 只读窗口，显示当前 todo 的 action、hash 和 subject；它对应参考 fork 的 `GitRebaseCommandsDialog`，不会修改 todo、selection 或 undo/redo history。
Interactive Rebase row context menu 补充：single-root 与 multi-root structured todo row 均按 topology 提供 Pick/Reword/Edit/Squash/Fixup/Drop/Commands…；merge row 只提供 Pick/Reword，在已有多选上从其中一行调用时保持整组选区语义，未选中行则只作用于该行。preserve-merges 未重排时开放同一 branch segment 的连续 Squash/Fixup，重排后暂时收窄为 pick/reword/edit/drop，跨 topology 边界 fail-closed。
Interactive Rebase no-op 补充：当 interactive rebase 没有可编辑提交时，single-root 与 multi-root 不再把 Start Rebase 静默禁用，而是按参考 `GitInteractiveRebaseEditorHandler.confirmNoopRebase()` 显示 Continue/Cancel 确认；multi-root 只统计成功加载且空 todo 的 root，加载失败仍阻止执行。

Interactive Rebase native control-row 补充：raw todo 的结构化预览现在允许直接编辑 `label/reset/merge/exec/update-ref` 的参数，并保持目标行之外的内容和 CRLF/LF 换行不变；`break` 仍以无参数停顿行展示，Git 继续负责最终语法验证。完整 control-row 重排/命令类型转换、通知分组和 UI automation 仍为 partial。

Interactive Rebase 帮助补充：Rebase 主对话框的 `--onto` 输入旁新增可聚焦的上下文帮助按钮，打开可取消的 SwiftUI popover，显示分支关系示意并链接到 `git-scm.com/docs/git-rebase`，对应参考 `GitRebaseHelpPopupPanel`。
